# 听页

个人音频播放器 PWA，支持英语、法语和日语。逐字稿、书签、词卡与播放位置保存在当前设备，可导出备份。手机音频默认保存本机副本，关闭重开可直接播放；可自行切换原文件模式，该模式重开需要重新选择文件。日语字体可选择黑体或明朝体。

这是静态网页，不使用付费转写接口。可选逐字稿同步由私人共享书库提供，只有获准账号可接收；音频、词卡与收听进度仍保存在设备。音频转写、日语词典分析及中文翻译在独立的电脑本地工具中完成，手机导入逐字稿 JSON 和对应原音频后可离线阅读与播放。网页不包含模型或个人音频。

播客支持订阅 Japanese with Shun 和 Learn Japanese with Noriko、搜索单集、喜欢及独立播放列表。默认在线播放，不自动下载音频。点击单集旁或播放器中的“下载”，完成后可离线播放；下载期间可取消，同一集不会重复保存。Noriko 下载显示状态，容量按节目提供的大小估算；Shun 可显示下载百分比。

设置 → 本机保存 → 播客下载与容量可查看占用、搜索下载、调整容量上限、单个或批量删除。默认 1 GB，达到上限后停止新增下载，不会自动删除。可选中已听完且未喜欢的单集，再核对清理名单。删除只移除下载，保留喜欢、逐字稿、词卡、进度和顺序；删除正在播放的下载会先暂停。下载时请保持听页打开，等显示“已下载”再锁屏。下载位于网页私有存储，不包含在学习备份中，更新网页会保留下载。

点击播放器音频来源按钮，进入“管理音频”可人工校对；双击词语打开词卡后，也可进入所在句子的校对。可修改原文、中文译文和日语假名，保存、导出或撤销最近一次修订。只改读音与译文保留全部词语时间轴；修改原文保留句子时间轴，变更词语的位置会估算。也可在音频库打开逐字稿文件校对后导出，无需音频。

支持遮盖精听、重复次数与间隔、完整词语词卡、按一行一词复制日语生词，跟随系统的夜间模式及七套色系（默认纸白）。自动读音、转写和译文可能有错误，请听音核对。手机精听计时的后台行为需在实际 iPhone 上验证。

用 Safari 打开网页，分享 → 添加到主屏幕，然后从主屏幕打开。请保留原音频，并定期在设置中导出备份。

GitHub Pages 可直接部署本目录，选择 main 分支根目录。所有路径均为相对路径。无需构建或第三方网页依赖。

音频库“更新文件夹”重新选择原目录，补入新音频并重连已有文件，保留学习资料及顺序；网页无法后台监视手机文件夹。原文件模式不保存音频副本。播放列表支持拖动 ≡ 手动排序、选择集数、随机播放和单集循环，独立于音频库顺序。长按下一句切下一集，长按上一句切上一集。

沉浸阅读居中显示当前句，A−／A+ 调整字号。点“精听”用横条遮盖原文与译文，单击句子切换遮盖与显示，双击单词打开词卡。循环设置包含次数、间隔、完成后暂停和听完是否显示。播放器右上角可设置原文／译文字号、字色及日语正文／沉浸字体。

电脑新版本支持免费本地上下文翻译及术语表，也可只重译旧逐字稿，保留原文和时间轴；人工改过的中文默认保留。首次需要下载模型，日常处理不使用付费接口。

译文开关控制已生成中文的显示；没有逐字稿或译文时会给出具体提示。电脑可直接补译当前逐字稿并应用回原音频，保留原文、假名与词语时间。精听遮挡开启时，译文开关控制点开遮挡后的中文显示。

播放器点击“精听遮盖”可同时遮盖原文和译文，点遮盖临时查看这一句。开关在本机记住，切换音频和重新打开仍生效，也与沉浸精听同步。

手机仍默认保存音频副本；电脑本机工具默认直接读取原文件，不保存音频副本。直接读取模式完全关闭浏览器后需重新选择原文件或同一文件夹，逐字稿、词卡和进度保留。电脑转写会临时处理音频，结束后自动清理。

新版电脑工具在“设置 → 逐字稿保存位置”中可浏览选择或粘贴文件夹路径，设置后各个逐字稿导出按钮会直接写入该文件夹；同名另存新版本。保存位置只在电脑记住，不进入手机备份或公开网页。关闭默认保存选项时恢复浏览器普通下载方式。

播放器点击“逐字稿”即可修改、调整断句、替换或导出稿件。替换会覆盖当前音频的全部旧稿并清除旧校对撤销记录，音频副本、播放进度和已保存词卡保留，不会追加新音频。

手机校对支持自动分句预览、拆分和合并下一句；可试听整句、前半句、后半句，也可用当前播放位置设置断句时间。保存直接更新本机，关闭后仍保留，无需再传回电脑。自动分句按标点、停顿和长度提出分界；缺少词语时间时会估算，需听音核对。拆开的原译文暂留在第一句作参考，新译文可在本机生成，也可人工填写。人工调整时间会校准越过分界的词语时间。仅打开逐字稿文件时，请导出修订文件后再关闭。

普通逐字稿可上下滚动、左右滑动切句；沉浸阅读可直接从文字上左右滑动浏览。手动浏览暂停自动跟随，点击该句右侧空白区才跳转播放；双击词语查看词卡，“回到播放”恢复显示跟随。双击同一单词打开词卡；单击句子切换精听遮盖，不跳转进度。键盘聚焦词语后可按 Enter 或空格打开词卡。

音频库可新建应用内文件夹，修改名称与封面照片，并选入已有音频。文件夹详情页右上角可再次编辑；取消选中将音频移回全部音频，选入另一个组则更新分组。分组不移动或复制手机原文件。封面和分组仅存本机，包含在学习备份中。文件夹内打开音频会按该组连续播放和排序，播放列表顶部可切换到全部音频。

音频列表和播放列表排序模式均支持拖动右侧“≡”手柄，松手自动保存为“我的顺序”；键盘聚焦手柄后可用上下箭头。普通滚动不会进入排序。排序保留其他分组和未显示音频的相对顺序。内容在独立区域滚动，底部播放器和导航保持固定。

手动浏览歌词不修改音频进度，播放／暂停按钮继续实际播放位置，不采用正在浏览句子的时间；点击句子右侧空白区才从该句开始播放。

词卡可在保存或编辑时填写自定义分类，留空为未分类；词卡页支持按语言、分类、原音频文件夹筛选，复习和词典导出使用当前筛选结果。分类随学习备份保存。听原句会使用当前逐字稿，从完整句子开头播放并在句尾暂停，支持旧词卡及重新连接原文件。播放列表排序仅显示拖动手柄，键盘聚焦手柄仍可用上下键。

拖动排序使用跟随手指的浮动音频行，其他行平滑让位，松手后归位并保存；靠近可见列表边缘时逐渐加速滚动，取消拖动会恢复原顺序。启用系统减少动态效果时保留跟手拖动并省略让位与归位动画。

播放器上方标题、播放进度和逐字稿工具栏固定，下方逐字稿独立滚动；进度条前段显示已播放的黑色刻度（深色模式使用浅色以保持可读）。词卡“导出到词典”支持当前筛选中的英语、法语、日语单词，保持一行一词。

导入、更新文件夹、导入逐字稿时添加新音频，以及重新选择旧音频，都默认保存本机副本，不另行询问。首次保存读取完整字节并回读核对，再提示成功。同名且内容相同的已保存音频复用原副本，不重写、不增加条目；新增文件保存到列表末尾。内容变化时创建新音频，保留旧学习资料。已保存副本用完整内容校验，避免仅检查文件头尾漏掉中间内容变化。旧版副本首次更新会校验并升级保存格式，之后直接复用。旧版未保存成功的音频需更新文件夹或重新选择一次，保留语言、逐字稿、词卡关联、分组、排序、书签和进度。

音频副本位于网页应用的私有本机存储，不显示在手机“文件”App，也不上传网站或公开仓库；可在“管理音频 → 导出原音频”中另存到“文件”。浏览器与主屏幕应用可能使用不同的数据空间，请在日常使用的入口导入。清理网站数据或移除应用可能清除本机资料，重要资料请保留备份。

普通播放器和沉浸精听都支持单击句子切换遮盖和显示，不显示“再次遮挡”按钮。手动重新遮盖不会立即被听完自动显示覆盖；切换句子后按精听设置继续。精听开关与原有本机偏好保持一致。

词卡从底部展开，突出所选词、读音、释义笔记、带高亮词语的原句和已有中文。可听完整原句，填写分类并保存。词义笔记来自人工保存，不自动编造词义。支持向下滑动或点击框外关闭，键盘仍可打开词卡。单击词语稍候执行句子遮盖，等待窗口内第二次点击同一个词会取消单击并打开词卡，滑动不触发这两个操作。


播放速度从底部倍速按钮旁弹出列表，当前速度带勾选；再次点倍速按钮、点空白或按 Escape 收起。选择倍速不打开对话框、不暂停音频、不重置逐字稿位置。普通播放器有独立的单句循环，持续重复当前句、不受精听重复次数或句间停顿限制；切换句子后循环新句。单句循环与原来的精听循环互斥，电脑模型保持不变。

普通界面的播放列表位于倍速后面；沉浸界面保持倍速、上一句、播放、下一句、播放列表的顺序。普通播放器显示“逐字稿”和“精听”；沉浸界面底部按“译文、读音、循环、精听、设置”排列，精听从顶部移到底部。精听设置从底部展开，支持下滑、点框外或关闭按钮收起；重复次数、间隔、遮盖、听完显示、暂停选项每次修改即保存，不再有保存按钮。

手机本机语音转写试用已经移除，语音识别继续使用电脑端工具。升级时只清理旧手机语音模型缓存，保留音频、逐字稿、词卡和进度。手机仍可导入、播放和替换电脑导出的逐字稿；校对与断句保留在电脑端。


手机／浏览器本机翻译试用和模型已经移除，中文翻译由电脑端工具处理。升级时只清理旧浏览器翻译权重与推理运行文件，保留音频、逐字稿、已生成译文、词卡及进度。底部音频、词卡和设置统一使用同色线条图标。


手机点击“逐字稿”直接替换，不再提供原文、假名、翻译或断句编辑入口；电脑端继续支持校对、断句及翻译。音频库“批量替换逐字稿”可选择文件夹或多选 JSON 文件，按不含扩展名的音频文件名匹配，兼容旧 .tingye.json；新导出使用原音频同名 .json。读取后先显示匹配和跳过原因，再统一替换，旧原文、译文、假名和校对记录完全覆盖，音频、词卡、进度、分组和顺序保留。重名、无匹配、空稿、大小或时间轴不符会跳过；提交前已有稿发生改变则整批取消。文件夹选择仅用于这一次读取，之后电脑更新文件需再次选择并替换，不会后台扫描手机文件。播放列表隐藏右上角关闭图标，保留下滑、框外点击、Escape 和顶部手柄关闭。


移除页面顶部的听页标识及“本机保存”字样，取消针对顶部模糊添加的页头样式；内容直接从设备安全区下方开始。


从音频库、词卡或链接打开音频时，自动将它加入对应播放范围的队尾，取消它之前的移出记录；已有队列顺序与音频库排序保留。打开已在队列中的音频不会重复添加。单集循环因此可以重复这段音频。电脑端已准备 MOSS 的环境，日语默认使用 MOSS GPU，再接原有中文翻译与校对；英语、法语保留原模型。


设置 → 本机保存 → 管理应用副本显示本机已保存的音频、文件名、分组和占用空间，支持搜索、按空间或名称排序、单个删除和批量删除。默认只删除音频字节，保留逐字稿、词卡、书签、进度和排序，重新选择原音频可补存；可在确认时主动勾选同时删除记录和学习资料。删除正在播放的副本会停止播放并释放音频，其他音频不受影响。选择全选只作用于当前搜索结果。手机“文件”中的原音频不会被删除。
