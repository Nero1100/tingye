# 听页

个人音频播放器 PWA，支持英语、法语和日语。逐字稿、书签、词卡与播放位置保存在当前设备，可导出备份。音频默认读取原文件，也可选择保存应用副本；关闭应用后，原文件模式需要重新选择文件。日语字体可选择黑体或明朝体。

这是静态网页，无账号、云端资料存储或付费接口。音频转写、日语词典分析及中文翻译在独立的电脑本地工具中完成，手机导入逐字稿 JSON 和对应原音频后可离线阅读与播放。网页不包含模型或个人音频。

点击播放器音频来源按钮，进入“管理音频”可人工校对；点词也可进入所在句子的校对。可修改原文、中文译文和日语假名，保存、导出或撤销最近一次修订。只改读音与译文保留全部词语时间轴；修改原文保留句子时间轴，变更词语的位置会估算。也可在音频库打开逐字稿文件校对后导出，无需音频。

支持遮盖精听、重复次数与间隔、完整词语词卡、按一行一词复制日语生词，跟随系统的夜间模式及七套色系（默认纸白）。自动读音、转写和译文可能有错误，请听音核对。手机精听计时的后台行为需在实际 iPhone 上验证。

用 Safari 打开网页，分享 → 添加到主屏幕，然后从主屏幕打开。请保留原音频，并定期在设置中导出备份。

GitHub Pages 可直接部署本目录，选择 main 分支根目录。所有路径均为相对路径。无需构建或第三方网页依赖。

音频库“更新文件夹”重新选择原目录，补入新音频并重连已有文件，保留学习资料及顺序；网页无法后台监视手机文件夹。原文件模式不保存音频副本。播放列表支持上移／下移手动排序、文件名自然排序和连续播放。长按下一句切下一集，长按上一句切上一集。

沉浸阅读居中显示当前句，A−／A+ 调整字号。点“精听”用横条遮盖原文与译文，可点开核对。循环设置包含次数、间隔、完成后暂停和听完是否显示。播放器右上角可设置原文／译文字号、字色及日语正文／沉浸字体。

电脑新版本支持免费本地上下文翻译及术语表，也可只重译旧逐字稿，保留原文和时间轴；人工改过的中文默认保留。首次需要下载模型，日常处理不使用付费接口。
